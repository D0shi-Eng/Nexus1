# ADR-003: أوامر IPC محددة وقدرات Tauri بأقل صلاحية

**الحالة:** مقبول  
**التاريخ:** 16 أغسطس 2026

## السياق

تعمل واجهة React داخل WebView، وقد يؤدي أي اختراق للواجهة أو محتوى غير موثوق إلى محاولة الوصول للملفات أو النظام أو البيانات المحلية. يطلب المنتج منع الوصول غير المقيد للصدفة والملفات والنظام، مع التحقق من مدخلات IPC وتدقيق العمليات الحساسة. تصف Tauri capabilities وpermissions كحدود صريحة للوصول، لكنها لا تلغي ضرورة تحقق Rust من النطاق والصلاحيات. [1] [2]

## القرار

سيستخدم التطبيق capabilities منفصلة وضيقة للنوافذ المعروفة فقط. لا تمنح الواجهة صلاحية shell أو filesystem أو SQL عامة. بدلاً من ذلك، تسجل النواة أوامر أعمال مخصصة؛ كل أمر يعرّف مدخلاته ومخرجاته بشكل مصنف، ويتحقق من الصيغة، ويستخرج السياق، ويفوض مركزياً، وينفذ نطاقاً محدوداً، ويدقق ما يلزم.

لا تعرض أوامر القراءة مسارات نظام أو رسائل Rust داخلية. ولا تقبل أوامر الاستيراد مساراً حراً؛ يتم اختيار الملف ضمن تدفق مقيد ثم يمر بمعالجة آمنة في Rust.

## البدائل التي روجعت

| البديل | القرار | السبب |
|---|---|---|
| السماح العام لـfilesystem/shell | مرفوض | يتعارض مع انعدام الثقة ومبدأ أقل صلاحية. |
| SQL plugin مباشر في React | مرفوض | يلغي حدود تطبيق التفويض ويزيد احتمال الاستعلامات غير المقيدة. |
| أوامر أعمال Rust محددة مع capabilities ضيقة | مقبول | يحقق تدقيقاً وتفويضاً وتحكماً بالنطاق وقابلية اختبار. |

## العواقب

يزيد عدد أوامر IPC المكتوبة لكنه يفرض عقوداً واضحة واختبارات أمان أفضل. كل أمر جديد عالي الأثر يحتاج مراجعة سياسة وcapability عند اللزوم. يحظر استخدام استدعاءات ديناميكية عامة أو تنفيذ سلاسل أوامر مستخدم.
