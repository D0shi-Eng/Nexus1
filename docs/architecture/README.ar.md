# معمارية NEXUS

**الإصدار 0.1.0** · Windows 11 x64 · Tauri 2 · Rust · React 19 · TypeScript · SQLite

يصف هذا المستند المعمارية **المنفَّذة فعلياً** في `apps/desktop`. كل عبارة هنا قابلة للتتبع إلى ملف في المستودع. أما المواد التصورية غير المبنية فتُوسم صراحةً ولا تُعرض أبداً كسلوك منتج.

## 1. شكل التطبيق

NEXUS **مونوليث وحدات محلي أولاً**. عملية سطح مكتب واحدة (Tauri) تضم:

| الطبقة | الموقع | المسؤولية |
|---|---|---|
| العرض | `src-tauri/src/presentation/` | 117 أمر `#[tauri::command]` مطبوعاً؛ يحوّل حمولات الواجهة إلى نداءات تطبيق ونتائج التطبيق إلى DTOs آمنة. |
| التطبيق | `src-tauri/src/application/` | حالات الاستخدام والسياسة: المصادقة، التفويض، الالتزامات، الأدلة، المهام، الموافقات، الضوابط، الوكلاء، المهارات، الأدوات، المعرفة، الذاكرة، الخطط، التقارير، التدقيق، النسخ الاحتياطي، المزوّدون، اللوحة، الاهتمام، الصحة. |
| النطاق | `src-tauri/src/domain/` | نماذج وقواعد بلا اعتماد على أطر: دورة حياة المهمة، سجل المزوّدين، تفويض الأدوات، طبقة الحقيقة، تعريفات التقارير، مفردات الأخطاء. |
| البنية التحتية | `src-tauri/src/infrastructure/` | قاعدة SQLite ومستودعاتها، محوّلات المزوّدين، خزنة DPAPI، السجل المحلي، عارضات التقارير، كاتب التصدير. |
| الواجهة | `apps/desktop/src/` | React 19، 15 وحدة تنقل، ثنائية اللغة RTL/LTR، 7 ثيمات، وصول بيانات عبر react-query فوق IPC، وعقود مشتركة من `packages/contracts`. |

اتجاه التبعية إلى الداخل: `presentation → application → domain`، وتُنفّذ `infrastructure` التخزين والإدخال/الإخراج الخارجي لصالح التطبيق. لا تعتمد طبقة النطاق على Tauri أو SQLite أو الشبكة.

## 2. نموذج الثقة والسلطة

- **الواجهة بلا سلطة.** لا ترسل هوية ولا مستأجراً ولا أدواراً ولا صلاحيات ولا تصنيفاً ولا ملكية. يستنتج `authorization_service::require_permission` كل ذلك من جلسة الخلف النشطة لكل أمر محمي.
- **فحص مربوط بالجلسة.** يستعلم فحص الصلاحية عن المستخدم النشط و**معرّف الجلسة النشطة بعينها** و`revoked_at` و`expires_at` وتعيينات الأدوار والصلاحيات. إبطال الجلسة يسري على الأمر التالي.
- **عزل المستأجرين.** الجداول التجارية تحمل `tenant_id`، وتفلتر المستودعات بالمستأجر النشط، وترفض مشغّلات SQLite نقل ملكية الأدلة بين المستأجرين.
- **سطح IPC أدنى.** `capabilities/main-capability.json` يمنح فقط `core:default` و`dialog:allow-open` و`dialog:allow-save`. لا صدفة ولا نظام ملفات عام ولا HTTP ولا وصول لقاعدة البيانات من الواجهة.
- **CSP محلية فقط:** `default-src 'self'; img-src 'self' data: asset:; style-src 'self' 'unsafe-inline'; script-src 'self'; connect-src 'self' ipc: http://ipc.localhost;`.

## 3. الاستمرارية

- قاعدة SQLite واحدة (`nexus-local.db`) في `%LOCALAPPDATA%\com.nexus.obligationos` لهوية الإنتاج، أو في حاوية `com.nexus.obligationos.uatharness` المعزولة للاختبارات.
- **26 هجرة مرقمة** (`0001 → 0026`) تُطبَّق عند الإقلاع، ويُسجَّل إصدار المخطط في `schema_migrations`.
- من الجداول الأساسية: `tenants` و`organizations` و`local_users` و`local_sessions` و`roles` و`permissions` و`regulatory_sources` و`obligations` و`evidence_items` و`tasks` و`approvals` و`risks` و`controls` و`audit_events` و`ai_provider_registry` و`ai_model_registry` و`agents` و`skills` و`tools` وجداول المعرفة والذاكرة.
- النسخ الاحتياطي يستعمل `VACUUM INTO` مع بيان (إصدار المخطط + SHA-256)، والاستعادة **تُبطل مرساة التدقيق صراحةً** ثم تُعيد تثبيتها.

## 4. التدقيق

- كل حدث يحمل تجزئة الحدث السابق وSHA-256 على حمولة الحدث؛ ويعيد `verify_audit_chain` حساب السلسلة كاملة ويقارنها بـ`audit-anchor.json` (تجزئة الذيل + عدد الأحداث).
- يكشف: تعديل حدث، حذفه، إعادة ترتيبه، تغيير الفاعل/المستأجر، واقتطاع الذيل.
- **لا يكشف** من يعيد كتابة القاعدة والمرساة معاً، ولا يحمي من مدير الجهاز. المنتج يعلن هذا القيد بدل ادعاء منع العبث المطلق.
- تُكتب أحداث التدقيق داخل معاملة التغيير التجاري نفسها؛ وفشل التدقيق يُلغي العملية.

## 5. تكامل مزوّدي الذكاء الاصطناعي

- عشرة أنواع ثابتة: Ollama، LM Studio، متوافق مع OpenAI، OpenAI، DeepSeek، Anthropic، Qwen، Z.ai، xAI، OpenRouter.
- المحوّلات: Ollama الأصلي (`/api/tags`، `/api/generate`، `/api/chat`)، المتوافق مع OpenAI (`/v1/models`، `/v1/chat/completions`)، رسائل Anthropic (`/v1/models`، `/v1/messages`).
- **البث غير منفَّذ** (كل الطلبات `stream: false`). استدعاء الأدوات والمخرجات المهيكلة منفَّذان في مسار Ollama الأصلي فقط، والمحوّلات الأخرى تفشل مغلقة بـ`CAPABILITY_NOT_IMPLEMENTED`.
- المفاتيح مشفّرة بـWindows DPAPI (نطاق المستخدم) ولا تُخزَّن في SQLite ولا السجلات ولا أحداث التدقيق ولا استجابات IPC.
- سياسة الوجهة: HTTPS إلزامي لغير الحلقي، وHTTP للحلقي `127.0.0.1` فقط، ورفض بيانات الاعتماد داخل العنوان، ورفض المضيفين الخاصين/link-local/الوصفيين، وتثبيت DNS بعد التحقق، وبلا تحويلات، وحدود حجم/مهلة.
- لا مزوّد مفعّل افتراضياً، ولا نداء بلا إجراء مستخدم صريح.

## 6. التقارير والتصدير

- ستة تعريفات محلية: `OBLIGATION_STATUS` · `RISK_REGISTER` · `EVIDENCE_REGISTER` · `CONTROL_EFFECTIVENESS` · `TASK_WORKLOAD` · `AUDIT_ACTIVITY`.
- الصفوف محدودة بـ500 لكل قسم، ويعلن التقرير `totalRows` و`truncated` بدل القص الصامت.
- صيغتا التصدير: CSV (هروب RFC 4180) وMarkdown، عبر حوار الحفظ الأصلي، بكتابة ذرّية محدودة وسياسة وجهة وحدث تدقيق لكل تصدير.
- كل تقرير يحمل منشأه ويعلن أنه **ملخص تشغيلي محلي وليس إقرار امتثال قانوني**.

## 7. طبقة العرض واللغتان

- العربية هي الاتجاه الافتراضي (`dir="rtl"`، `lang="ar"`)، والإنجليزية تقلب المستند كاملاً إلى LTR بلا إعادة تحميل.
- سبع تفضيلات مظهر: فاتح، داكن، منتصف الليل، رملي، زمردي، تباين عالٍ، والنظام.
- النافذة مقيسة عند الحد الأدنى المعلن 980×640 وعند 1100×700 و1280×820، في الاتجاهين وكل الثيمات المقيسة.
- الوصولية: حصر التركيز بلوحة المفاتيح داخل الحوارات، واستعادة التركيز بعد Escape، وأسماء قارئ الشاشة قيست بـNVDA على الحزمة المشحونة.

## 8. خارج النطاق عمداً في V1

المزامنة السحابية، والتكرار متعدد الأجهزة، وSSO/MFA، والتغذية التنظيمية الحية، والاسترجاع الدلالي/المتجهي، وإدخال PDF، وتأليف المخاطر، والاختبار الآلي للضوابط، وتنفيذ الوكلاء في الخلفية، وتوقيع الثنائيات، والتحديث التلقائي — **كلها غير منفَّذة**، ولا تُرسم في المخططات ولا يُدَّعى وجودها في التوثيق.
