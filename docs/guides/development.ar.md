# دليل التطوير

**ينطبق على:** NEXUS V1 `0.1.0`.

هذا الدليل للمطورين الذين سيبنون المصدر ويختبرونه ويغيّرونه. اقرأ [المعمارية](../architecture/README.ar.md) أولاً لفهم شكل النظام.

---

## 1. بنية المستودع

```text
apps/desktop/                 واجهة React 19 + TypeScript وتطبيق Tauri/Rust
  src/                        الواجهة: القشرة، 15 وحدة ميزات، مكوّنات، مكتبات، لغات، أنماط
  src-tauri/                  نواة Rust: domain / application / infrastructure / presentation
  src-tauri/migrations/       هجرات SQLite المرقمة 0001 → 0026
  public/                     خطوط مضمّنة (IBM Plex Sans Arabic، OFL) وبذور المظهر
packages/contracts/           عقود TypeScript المشتركة (@nexus/contracts)
tools/                        حزم e2e/ضمان الجودة، فاحص الأسرار، أدوات الخطوط والثيمات
docs/                         المعمارية والأدلة وقرارات ADR ومصفوفة AI والإشعارات القانونية وملاحظات الإصدار
.github/workflows/ci.yml      CI للقراءة فقط (JavaScript، Rust، صحة المصدر)
assets/branding/              أصول العلامة المصدرية ومخرجات PNG/ICO
```

## 2. سلسلة الأدوات

| الأداة | المتطلب |
|---|---|
| Node.js | >= 22 (CI: 24) |
| npm | >= 10؛ والقفل مولّد بـ`npm@11.11.0` |
| Rust | >= 1.77.2 (سلسلة MSVC مع `rustfmt`) |
| Tauri CLI | اعتمادية تطوير (`@tauri-apps/cli`) |
| Windows | Windows 11 مع WebView2 Runtime وأدوات بناء MSVC |

## 3. الإعداد الأول

```powershell
git clone https://github.com/D0shi-Eng/Nexus1.git
cd Nexus1
npm ci
npm run desktop -- dev
```

يُشترط `npm ci` للحتمية؛ ولا تودِع قفلاً معدّلاً يدوياً بلا سبب ملموس.

## 4. الأوامر التي ستستعملها فعلاً

| الغرض | الأمر |
|---|---|
| الواجهة وحدها (Vite) | `npm run dev` |
| نافذة سطح المكتب الكاملة | `npm run desktop -- dev` |
| التحقق من الأنواع | `npm run typecheck` |
| Lint (صفر تحذيرات) | `npm run lint` |
| اختبارات JS/TS | `npm run test` |
| بناء واجهة الإنتاج | `npm run build` |
| بناء إصدار سطح المكتب | `npm run tauri --workspace=@nexus/desktop -- build` |
| فحص تنسيق Rust | `cargo fmt --check` (داخل `apps/desktop/src-tauri`) |
| فحص Rust لكل الأهداف | `cargo check --all-targets` |
| اختبارات Rust (تسلسلي) | `cargo test --lib -- --test-threads=1` |
| فحص الأسرار | `node tools/security/secret-scan.mjs` |

> يُشغَّل `cargo test` تسلسلياً لأن بعض الاختبارات تمس أسطح DPAPI وSQLite ولا آمن تشغيلها تزامنياً في هذه البيئة.

## 5. استراتيجية الاختبار

- **الواجهة:** Vitest + jsdom. تغطي اختبارات عقد التنقل وصحة اللغات ورموز التصميم وعقد نظام التصميم وصفحات الوحدات والحوارات وتحويل أخطاء API.
- **Rust:** اختبارات وحدات بجوار الشيفرة (`*_tests.rs`) تغطي المصادقة والتفويض وعزل المستأجرين وسلسلة التدقيق والمرساة وعقود وإعدادات المزوّدين ودورة حياة المهمة والموافقات والأدلة والضوابط والتقارير والمعرفة والذاكرة والنسخ الاحتياطي والحالات السلبية الأمنية.
- **من طرف لطرف:** نافذة Tauri WebView2 حقيقية تُقاد عبر CDP على **حاوية معزولة** بمعرّف تطبيق منفصل. وتغطي الحزم دورة إنتاج كاملة ودورة ديمو وواجهة/لغات/ثيمات/وصولية وحوارات حفظ أصلية ومصفوفة حجم النافذة.
- **لا اختبار أبداً على قاعدة مستخدم حية.** تستعمل الحزمة `com.nexus.obligationos.uatharness`، والصور تستخدم بيانات ديمو تركيبية فقط.

المقيس على شجرة الإصدار: **202 اختبار JavaScript في 34 ملفاً** و**622 اختبار Rust ناجحاً و10 متجاهلة**. وهذه أرقام من تشغيل فعلي لا من ادعاء توثيقي؛ أعد تشغيل البوابات قبل تغييرها.

## 6. قواعد معمارية للتغييرات

1. **السلطة تبقى في Rust.** لا تثق بالواجهة في الهوية أو المستأجر أو الدور أو الصلاحية أو التصنيف أو الملكية.
2. **كل أمر محمي جديد يستدعي `require_permission`** بصلاحية موجودة في الكتالوج؛ ولا تُضف نص صلاحية دون إضافته إلى `ensure_permission_catalog` وبذور الأدوار.
3. **التدقيق جزء من الكتابة.** تغييرات الأعمال وحدث تدقيقها يُثبتان في المعاملة نفسها.
4. **النطاق بلا أطر.** لا أنواع Tauri أو SQLite أو HTTP داخل `domain/`.
5. **لا مسار شبكي جديد بلا فحص سياسة الوجهة.** HTTPS لغير الحلقي، وHTTP للحلقي فقط، وتثبيت DNS، وبلا تحويلات، وحدود حجم/وقت.
6. **الواجهة تعلن الحدود.** إن كانت القدرة غير منفَّذة، اعرض ذلك بصدق بدل عنصر تحكم بلا وظيفة.
7. **الهجرات إضافية فقط.** أضف `0027_*` بدل تعديل هجرة مطبَّقة.
8. **التغطية ثنائية اللغة جزء من التغيير.** كل نص للمستخدم يمر عبر `locales/ar.ts` و`locales/en.ts`، وتبقى اختبارات اللغات ناجحة.

## 7. قواعد الأمن والنظافة

- لا أسرار في المستودع: مفاتيح أو رموز أو كلمات مرور أو `.env` أو شهادات أو قواعد محلية أو سجلات أو مخرجات بناء.
- لا مسارات مطوّر مطلقة في الشيفرة أو الاختبارات أو التوثيق أو رسائل الالتزام.
- لا موارد وقت تشغيل بعيدة (CDN/خطوط/سكربتات)؛ فـCSP تمنعها تصميماً.
- الفاحص: `node tools/security/secret-scan.mjs` يجب أن يخرج نظيفاً قبل أي نشر.
- لا تُضعف اختباراً فاشلاً ليمر CI؛ أصلح السبب.

## 8. التكامل المستمر

`.github/workflows/ci.yml` يعمل على Windows بصلاحية `contents: read` فقط:

- **بوابات JavaScript:** `npm ci` ثم typecheck ثم lint ثم اختبارات ثم build.
- **بوابات Rust:** `cargo fmt --check` ثم `cargo check --all-targets` ثم `cargo test --lib -- --test-threads=1`.
- **صحة المصدر:** أنماط أسرار عالية الثقة وفحص مخرجات ممنوعة (لا `.exe` أو `.db` أو `node_modules` أو `target` أو مخرجات تدقيق خام متعقّبة).

لا ينشر سير العمل أي مخرجات، ولا يطلب رمز كتابة، ولا يستخدم اعتمادات مزوّدين أو APIs مدفوعة.

## 9. هندسة الإصدار

مسار الإصدار قابل لإعادة الإنتاج لكنه **غير موقّع**:

```powershell
pwsh -File apps/desktop/src-tauri/build-release.ps1
```

يعيد السكربت ربط مسار ملف تعريف الباني (`--remap-path-prefix`) كي لا تتسرب مسارات البناء المطلقة إلى الملف التنفيذي. تحقق من أي ثنائي تنتجه قبل توزيعه؛ فالمشروع لا يوزّع مثبّتات وليست لديه شهادة توقيع.

## 10. قواعد التوثيق

- كل ادعاء واقعي في التوثيق يجب أن يكون قابلاً للتتبع إلى المصدر؛ وإن لم يكن، يُحذف.
- المخططات ملفات Mermaid مصدرية تحت `docs/architecture/diagrams/`؛ ولا صور ملفّقة ولا رسومات تسويقية.
- الصور تُلتقط من التطبيق الحقيقي ببيانات ديمو تركيبية، ولا تُلتقط أبداً من قاعدة مستخدم.
- حافظ على تكافؤ المستندين العربي والإنجليزي في الحقائق والتغطية؛ والترجمة تغيّر الصياغة لا الادعاءات.

## 11. مسار المساهمة

1. افتح Issue يصف التغيير (أو ناقشه مع المشرف أولاً).
2. تفرّع من `main` بـ`feature/*` أو `fix/*`.
3. نفّذ وأضف الاختبارات وحدّث نسختي اللغة من التوثيق المتأثر.
4. شغّل كل البوابات في §4 محلياً و`node tools/security/secret-scan.mjs`.
5. افتح Pull Request ووضّح ما تم التحقق منه وما لم يتم.

`SECURITY.md` و`CONTRIBUTING.md` يحملان السياسات الملزمة. وإصلاحات الأمن تتبع مسار الإفصاح الخاص لا PR عاماً.
