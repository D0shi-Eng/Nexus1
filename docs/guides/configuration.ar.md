# دليل الإعداد

**ينطبق على:** NEXUS V1 `0.1.0`.

يُعدّ NEXUS من واجهته ومن قاعدة SQLite المحلية. **المنتج لا يقرأ ملف `.env` ولا ملف أسرار ولا خدمة إعداد بعيدة.** لا يوجد مفتاح تليمتري ولا مشروع سحابي ولا عنوان خادم لتكوينه.

---

## 1. موضع الإعداد

| العنصر | الموضع | ملاحظات |
|---|---|---|
| بيانات التطبيق | `%LOCALAPPDATA%\com.nexus.obligationos\` | هوية الإنتاج (`com.nexus.obligationos`) |
| قاعدة البيانات | `...\nexus-local.db` | المستأجرون والمستخدمون والأدوار وسجلات الأعمال والمزوّدون والتدقيق |
| مرساة التدقيق | `...\audit-anchor.json` | تجزئة الذيل + عدد الأحداث المثبتة |
| السجل المحلي | `...\logs\` | سطور تشغيلية فقط؛ بلا أسرار وبلا حمولات أعمال |
| تفضيل المظهر | تخزين WebView المحلي (`nexus.theme`) | تفضيل واجهة فقط |
| اللغة | مبدّل داخل التطبيق | العربية RTL افتراضياً والإنجليزية LTR |
| حاوية اختبار معزولة | `%LOCALAPPDATA%\com.nexus.obligationos.uatharness\` | معرّف تطبيق مختلف؛ ليست القاعدة الحية أبداً |

أداة الإزالة لا تحذف مجلد البيانات. المثبّت وبيانات التطبيق منفصلان عمداً.

## 2. أقسام الإعدادات (المنفَّذة)

افتح **الإعدادات** من أسفل شريط التنقل. تُعرض الأقسام الموجودة فعلاً فقط:

| القسم | ما يضبطه | الصلاحية |
|---|---|---|
| **عام** | هوية المنتج ووضع التشغيل النشط (DEMO أو PRODUCTION) | أي عضو مسجّل |
| **المظهر** | تفضيل المظهر: فاتح، داكن، منتصف الليل، رملي، زمردي، تباين عالٍ، النظام | أي عضو مسجّل |
| **اللغة والمنطقة** | العربية/الإنجليزية واتجاه المستند | أي عضو مسجّل |
| **مزوّدو الذكاء الاصطناعي** | سجل المزوّدين: إضافة، تكوين، اختبار اتصال، اكتشاف نماذج، تعيين/استبدال/مسح الاعتماد | `integration:read`؛ وكتابة الاعتماد تتطلب `integration:credential` |
| **نماذج الذكاء الاصطناعي** | اختيار النماذج المكتشفة للتنفيذ المحلي | `integration:update` |
| **البيانات والأمان** | مستخدمو مساحة العمل والأدوار، النسخ الاحتياطية، معلومات الجلسة | `user:read` / `backup:create` |
| **الأمان وكلمة المرور** | تغيير كلمة مرورك (إنتاج فقط) | أي عضو إنتاجي مسجّل |
| **حول والتشخيص** | الإصدار والوضع والصحة وقائمة صادقة بما لا يوجد من إعدادات | أي عضو مسجّل |

وكل ما ليس منفَّذاً يُذكر في **حول والتشخيص** بدل عرضه كمفتاح وهمي.

## 3. اللغة والاتجاه

- الافتراضي: العربية (`lang="ar"`، `dir="rtl"`).
- التبديل إلى الإنجليزية يقلب المستند كاملاً إلى LTR ويوطّن التنقل والجداول والحوارات والأخطاء.
- التواريخ والأرقام تتبع اللغة النشطة.
- تغيير اللغة لا يعيد تحميل التطبيق ولا يغيّر البيانات المخزنة.

## 4. المظهر

تُخزَّن سبعة تفضيلات وتُطبَّق: `light` و`dark` و`midnight` و`sand` و`emerald` و`contrast` و`system`. وثيم التباين العالي يزيد عرض الحدود والتباين، وقيس التباين النصي ≥ 4.5:1 عبر الواجهة.

## 5. حجم النافذة

الحد الأدنى المعلن: **980 × 640**. والافتراضي: 1360 × 880. ويُمنع التصغير تحت الحد الأدنى من مدير النافذة. وقد قيست مصفوفة التخطيط عند 980×640 و1100×700 و1280×820 في RTL وLTR مع ثيمات فاتح/داكن/تباين.

## 6. إعداد مزوّد الذكاء الاصطناعي

صفوف المزوّدين **داخل نطاق المستأجر** وتبدأ معطّلة. ويُبذر صف Ollama المدمج بحالة `UNVERIFIED` ومعطّلاً.

خطوات الإعداد:

1. **الإعدادات ← مزوّدو الذكاء الاصطناعي ← إضافة مزوّد**.
2. اختر أحد الأنواع العشرة الثابتة. يُملأ العنوان الأساسي فقط حيث توثّقه الجهة المالكة؛ وإلا يبقى الحقل فارغاً وتدخله أنت.
3. عيّن العنوان الأساسي. السياسة: HTTPS لغير الحلقي، وHTTP فقط على `127.0.0.1`، ورفض بيانات الاعتماد داخل العنوان، ورفض المضيفين الخاصين/link-local/الوصفيين.
4. **تعيين اعتماد** — يُخزَّن بـWindows DPAPI (نطاق المستخدم) ومرتبطاً بصف المزوّد. لا يُكتب المفتاح في SQLite ولا السجلات ولا أحداث التدقيق ولا استجابات IPC، ولا يُعرض مجدداً بعد الحفظ.
5. **اختبار الاتصال** ← نداء حقيقي إلى الوجهة المتحقق منها وتسجيل الحالة.
6. **اكتشاف النماذج** ← نداء مسار تعداد النماذج. وفي Qwen وZ.ai هذا المسار غير موثّق من الجهة المالكة، فقد يفشل الاكتشاف وتُعلن الواجهة الفشل بدل اختراع نماذج.
7. **الإعدادات ← نماذج الذكاء الاصطناعي** ← اختيار نموذج مكتشف للتنفيذ المحلي.

> حفظ الاعتماد **لا** يوسم المزوّد متصلاً. الاختبار الحي الناجح وحده يفعل ذلك.

### سياسة الوجهة (مفروضة في Rust)

| القاعدة | السلوك |
|---|---|
| مخطط غير محلي | `https://` إلزامي |
| الحلقي | يُسمح `http://127.0.0.1` |
| بيانات اعتماد في العنوان | مرفوضة |
| مضيفون خاصون / link-local / `.local` | مرفوضون |
| DNS | يُحلّ ويُثبَّت بعد التحقق (منع إعادة الربط) |
| التحويلات | لا تُتبع |
| الحجم والوقت | محدودان لكل طلب/استجابة |
| تفعيل المزوّد | صريح؛ بلا نداءات تلقائية |

## 7. النسخ الاحتياطية

- أنشئ نسخة من **الإعدادات ← البيانات والأمان** (الصلاحية `backup:create`).
- الصيغة: `VACUUM INTO` في SQLite مع بيان يحمل إصدار المخطط وSHA-256.
- تتحقق الاستعادة من البيان و**تُبطل مرساة التدقيق صراحةً**، وتُعاد المرساة عند أول تحقق ناجح للسلسلة بعد الاستعادة.
- النسخ تحتوي بيانات أعمال؛ خزّنها بما يليق بها. ولا يشفّرها NEXUS بما يتجاوز حماية ملف تعريف Windows للمستخدم.

## 8. كلمات المرور والجلسات

- سياسة كلمة المرور: 12–128 حرفاً، كبير + صغير + رقم + رمز.
- التجزئة: Argon2id.
- عمر جلسة الإنتاج: 12 ساعة.
- القفل: 5/10/15 محاولة فاشلة ← 60/300/900 ثانية.
- تغيير كلمة المرور يُبطل الجلسة السابقة.
- تغيير اللغة أو المظهر لا يؤثر على الجلسة.

## 9. متغيرات بيئة للتطوير فقط

هذه تسهيلات بناء/اختبار وليست إعداد منتج:

| المتغير | يستخدمه | الغرض |
|---|---|---|
| `CARGO_TARGET_DIR` | سكربتات بناء Tauri/Rust | إبقاء مخرج البناء خارج المستودع |
| `RUSTFLAGS` | `build-release.ps1` | إعادة ربط المسارات لمنع تسريب مسارات الباني إلى الثنائي |
| `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` | حزمة e2e | فتح منفذ CDP محلي في بناء اختبار معزول فقط |

المنتج نفسه لا يقرأ أياً منها لسلوكه، ولا شيء منها سر.

## 10. ما لا يمكن إعداده في V1

لا يوجد إعداد للمزامنة السحابية، أو SSO/MFA، أو البريد/SMTP، أو قناة تحديث، أو التحليلات، أو سجلات خارجية، أو عناوين خادم متعدد المستأجرين — لأن هذه القدرات غير موجودة. والواجهة لا تدّعي غير ذلك.
